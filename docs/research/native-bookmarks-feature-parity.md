`HEADLESS=0 node scripts/test-chrome-extension.mjs --native-bookmarks --mouse` 在隔离的可见 Chrome for Testing 中使用 CDP 鼠标按下、移动、释放和键盘输入；不通过 DOM 合成拖拽事件。
覆盖新增书签/目录、修改名称和网址、重命名、向前/向后排序、拖入目录中央/侧栏、通过面包屑移出、文件夹跨目录移动，并回读原生书签验证。
修复同目录向后排序的重复索引调整；Chrome 本身会在移除源节点时调整目标索引。
同时修复浏览器测试等待器未等待 Promise 导致的假通过，后续异步断言必须等待实际结果。

### 左侧导航拖拽补齐

左侧普通文件夹可以直接拖起，导航项上/下四分之一区域用于前/后插入，中间区域用于移入。导航保持原生顺序，不受右侧搜索和展示排序影响。系统目录不能拖起；移动前仍重读原生树检查保护目录和循环关系。
可见 Chrome 鼠标验收覆盖从左侧拖起的向上/向下排序、跨父目录边缘插入、中央移入、面包屑移出、禁止移入子目录和系统目录不可拖起。鼠标脚本在最终落点等待渲染帧后释放，避免浏览器合并快速输入时尚未命中目标就释放。

### 打开位置设置

工具栏“打开书签时”提供“恢复上次状态”（默认）与“始终显示最顶层”。恢复保存的文件夹、导航展开状态、网格/列表与排序，不恢复临时搜索或滚动位置。最顶层模式打开“浏览器书签”，导航初始收起；不会改变当前标签页的位置。旧 defaultFolderId 用作首次恢复位置，旧设置不直接丢弃。数据仅存在本地 nativeBookmarkPreferences，不修改 Chrome 书签树；新标签页回读配置验证两种模式。

### 图标加载超时诊断（2026-10-28）

新增打开位置测试创建了其他标签页，原截图页留在后台。失败点实测 `document.visibilityState === 'hidden'`，六张 `loading="lazy"` 图片均 `complete === false`。后台懒加载不是 favicon 请求失败；延长超时无效。截图阶段显式 `Page.bringToFront` 并等待 `visibilityState === 'visible'`，保留原图标完成断言和超时后，`npm run test:bookmarks` 完整通过。未改变产品图标加载策略、网络权限或外部图标访问设置。

### 主页入口精简（2026-10-28）

根据后续反馈，移除虚拟“浏览器书签”导航和面包屑层级，初始/失效位置直接落在浏览器返回的首个真实顶层目录；其他顶层目录仍在侧栏独立保留，不依赖硬编码 ID 或名称。
“打开书签时”迁至通用设置，默认恢复上次状态；另一个选项为打开首个顶层文件夹。
新增书签/文件夹迁至右键菜单（目录项或内容区空白处），默认目标为右键目录/当前目录。工具栏仅留“…”用于键盘和触屏；菜单支持箭头键、Escape 和点击外部关闭。
真实鼠标右键新增、左侧拖拽、编辑/重命名与完整浏览器回归通过。修复右键弹出自动 popover 在释放鼠标时立即关闭的问题，显式处理关闭时机。

### 右键菜单合并

编辑/重命名、移动到、删除直接显示在右键菜单中，项目“…”打开同一菜单，不再先打开“管理”中转弹窗。选择操作后仅出现对应编辑表单、目录选择或删除确认。完整浏览器回归和可见 Chrome 鼠标验收通过，鼠标测试明确断言打开项目菜单时没有 dialog，且三项操作直接可用。
